# Quilibrium Quorum Mandala Generator

## Project Overview
A web application for generating mandala visualizations based on Quilibrium network quorum data.

## Development Commands
- Run development server: `npm run dev` (if using npm) or check package.json for scripts
- Build: `npm run build`
- Test: `npm test`
- Lint: `npm run lint`
- Type check: `npm run typecheck`

## Tech Stack
- React/TypeScript (based on .tsx files)
- PNG export functionality
- Web-based mandala generation

## File Structure
- `quorum-mandala-generator.tsx` - Main React component
- `assets/js/png-export.js` - PNG export functionality
- `index.html` - Main HTML entry point

## Notes
- Project uses Nunito font with fallback for PNG export
- Recent work includes PNG export improvements
